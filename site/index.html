What this shows

A compact, real model export

This is the full_7k web subset, not the larger 30k model. The archived gsplat evaluation gives 27.76 dB held-out PSNR for the full 7k model and 26.56 dB for this pruned, zero-order-colour subset. Those are recorded offline measurements, not a new browser accuracy benchmark.

Known limits

Look around, with context

Moving objects are not modelled. Near-camera floaters, blurred textures and gaps outside the captured path remain visible. Off-path views have no RGB ground truth. This single, short clip does not establish general driving-scene performance.

WebGL 2 and WebAssembly are required. High-density screens render at one device pixel per CSS pixel to limit buffer size. No phone frame-rate or memory guarantee is claimed; the preview is available without loading the scene.
